  - findById(id)        : SELECT * WHERE id=? AND deleted_at IS NULL

  - update(id, data)    : strips id/created_at, sets updated_at; calls enqueueSync
  - softDelete(id)      : sets deleted_at=now(); calls enqueueSync
  - enqueueSync(table, id, op, payload): inserts to sync_queue (skips sync_queue + audit_log tables)

company.repo.js (extends BaseRepository)
  - Overrides insert(): runs a TRANSACTION that:
    1. Creates the company record (super.insert)
    2. Creates "Standard Structure" salary_structure
    3. Seeds 12 default salary components:

       CONV (fixed 1600), MED (fixed 1250),
       SA (formula: MONTHLY_CTC-BASIC-HRA-DA-CONV-MED),
       PF_EMP (statutory pf_employee), PF_ER (statutory pf_employer),
       ESI_EMP (statutory esi_employee), ESI_ER (statutory esi_employer),

  - Implements Automation Rule #7

employee.repo.js (extends BaseRepository)
  - Overrides insert(employeeData, identityData, statutoryData): TRANSACTION that:
    1. Creates employees record
    2. Creates employee_identity record
    3. Creates employee_statutory_config with employment-type defaults:
       permanent  : all flags ON (pf=1, esi=1, tds=1, pt=1)
       contract   : pf=0, esi=0, tds=1, pt=1
       intern     : pf=0, esi=0, tds=0, pt=0
       probation  : same as permanent
       part_time  : same as permanent
  - getEmployeePackage(empId): LEFT JOINs core + identity + statutory + latest salary

  - saveInvestmentDeclaration(declaration): upsert to employee_investment_declaration

  - getSalaryMappings(companyId): LEFT JOIN employees + employee_salary + salary_structures

--- payroll.engine.js (main orchestrator) ---
  Function: processPayroll(companyId, month, year, operatorName)
  Returns:  { runData, detailsArray, overridesArray }
  NOTE: Does NOT save to DB — caller (payrollService.executeAndSavePayroll) commits.

  Step 1: Load company via getDB().prepare('SELECT * FROM companies WHERE id=?').get(companyId)
  Step 2: getFinancialYear(month, year) — April(4) is start of FY; e.g. month=4,year=2025 -> FY 2025-26
  Step 3: Load PFConfig = statutoryRepo.getPFConfig(companyId)
  Step 4: Load ESIConfig = statutoryRepo.getESIConfig(companyId)
  Step 5: Load TDSConfig = statutoryRepo.getTDSConfig(finYear, empStatutory.tds_regime)
  Step 6: Load active employees = getDB().prepare('SELECT * FROM employees WHERE company_id=? AND status=active AND deleted_at IS NULL').all(companyId)
  Step 7: Per employee loop:
    a. Load employeePackage = employeeRepo.getEmployeePackage(empId)
    b. Load salary = salaryRepo.getEmployeeSalary(empId)  [skips if none]
    c. Load salary components = salaryRepo.getStructureWithComponents(structure_id)
    d. Load attendance = attendanceRepo.getAttendanceLog(empId, month, year)
       If no attendance record: defaults to full month (lop_days=0)
    e. Load YTD metrics = statutoryRepo.getYTDMetrics(empId, finYear)
    f. Load YTD basic/HRA via direct SQL on payroll_details
    g. Load pre-existing overrides = payrollRepo.getEmployeeOverrides(existingRunId, empId)
    h. Apply override amounts to earnings (bonus/arrear add to gross, advance deducted)
    i. Call calculateEarnings(employee, components, salary, attendance) -> earningResult
    j. Call calculatePF(employee, empStatutory, pfConfig, earningResult) -> pfResult
    k. Call calculateESI(employee, empStatutory, esiConfig, earningResult) -> esiResult
    l. Call calculatePT(employee, empStatutory, company, month) -> ptResult
    m. Call calculateTDS(employee, empStatutory, tdsConfig, earningResult, ytdMetrics, month) -> tdsResult
    n. Compute advance_recovery from empStatutory.is_advance_recovery_active
    o. Build payroll_details row with all computed values + computation_log JSON
  Step 8: Aggregate totals for payroll_runs row
  Step 9: Return { runData, detailsArray, overridesArray }

--- earnings.calculator.js ---
  Function: calculateEarnings(employee, components, salary, attendance)

  Context object built for formula evaluation:
    MONTHLY_CTC, BASIC, HRA, DA, CONV, MED, SA (and all other component codes)

  Component resolution order (by display_order):
    1. fixed: use calc_value directly
    2. pct_ctc: (calc_value / 100) * monthly_ctc
    3. pct_basic: (calc_value / 100) * BASIC (resolved earlier in loop)
    4. formula: evaluateFormula(calc_value, context) using new Function()
    5. statutory: skipped in earnings phase (handled by dedicated calculators)

  evaluateFormula(formula, context):
    - Converts context keys to let bindings
    - Executes via new Function('...', `return ${formula}`)
    - Safe arithmetic only (no arbitrary code)

  LOP pro-rating (applied to earning components with is_pro_rated=1):
    lopAdjustment = (baseAmount / workingDays) * lopDays
    finalAmount = baseAmount - lopAdjustment

  Wage base accumulation:
    pfWageBase  : sum of earnings where is_pf_wage=1
    esiWageBase : sum of earnings where is_esi_wage=1
    taxableBase : sum of earnings where is_taxable=1

  Returns: { components: {CODE: amount, ...}, pfWageBase, esiWageBase, taxableBase,
             grossSalary, basic, hra, monthly_ctc }

--- pf.calculator.js ---
  Function: calculatePF(employee, empStatutory, pfConfig, earningResult)

  Gating:
    - company.is_pf_registered must be truthy
    - empStatutory.is_pf_enabled must be 1

  PF wage:
    pfWage = pfConfig.is_ceiling_applicable
               ? Math.min(pfWageBase, pfConfig.wage_ceiling)   // typically 15000
               : pfWageBase

  Employee PF   = round2(pfWage * pfConfig.employee_contribution_pct / 100)  // 12%
  VPF (if voluntary pf_contribution_type):
    vpf = round2(pfWageBase * empStatutory.voluntary_pf_pct / 100)

  EPS:
    If at ceiling: eps_ceiling (1250)
    Else: round2(pfWage * pfConfig.eps_pct / 100)             // 8.33%

  Employer EPF  = round2(pfWage * pfConfig.employer_contribution_pct / 100) - EPS  // 12% - EPS
  EDLI          = round2(pfWage * pfConfig.edli_pct / 100)    // 0.5%

  Returns: { pf_employee, vpf, eps_contribution, pf_employer, edli_contribution,
             pf_wage_used, esi_ceiling_crossed: false }

--- esi.calculator.js ---
  Function: calculateESI(employee, empStatutory, esiConfig, earningResult)

  Gating:
    - company.is_esi_registered must be truthy
    - empStatutory.is_esi_enabled must be 1

  Ceiling check:
    If esiWageBase > esiConfig.wage_ceiling (21000):
      return { esi_employee: 0, esi_employer: 0, esi_ceiling_crossed: 1 }

  Employee ESI  = round2(esiWageBase * esiConfig.employee_contribution_pct / 100)  // 0.75%
  Employer ESI  = round2(esiWageBase * esiConfig.employer_contribution_pct / 100)  // 3.25%

  Returns: { esi_employee, esi_employer, esi_ceiling_crossed, esi_wage_used }

--- pt.calculator.js ---
  Function: calculatePT(employee, empStatutory, company, month, grossSalary)

  Gating:
    - company.is_pt_applicable must be truthy
    - empStatutory.is_pt_enabled must be 1

  State resolution: empStatutory.pt_state_override || company.state_code

  Config: getPTConfig(stateCode) -> slabs array

  Slab matching:
    Find first slab where: grossSalary >= slab.min AND (slab.max IS NULL OR grossSalary <= slab.max)
    Return slab.amount

  Maharashtra February special:
    If stateCode='MH' AND month=2 AND grossSalary > 10000: return 300

  Returns: { professional_tax }

--- tds.calculator.js ---
  Function: calculateTDS(employee, empStatutory, tdsConfig, earningResult, ytdMetrics, month, year)

  Gating:
    - company.is_tds_deductor must be truthy
    - empStatutory.is_tds_enabled must be 1
    - tdsConfig must exist for regime

  Monthly apportionment:
    monthsRemaining = April(4)=12, May(5)=11, ..., March(3)=1
    projectedAnnualGross = ytdMetrics.ytd_gross + (monthlyTaxableGross * monthsRemaining)

  Standard deduction:
    New regime: 75000
    Old regime: 50000

  Old regime deductions:
    HRA exemption: min(actual_hra, metro?50%:40% of basic, rent_paid - 10% of basic)
    80C: capped at 150000
    80D (self/parents/senior parent): per-slab limits
    Section 24b (home loan interest): capped at 200000
    NPS 80CCD(1B): as declared
    80E: education loan interest (full)
    80G: as declared

  Slab tax calculation:
    Iterates slabs from tdsConfig.slabs_json
    Each slab: tax += (min(income, slab.max) - slab.min) * slab.rate / 100

  87A Rebate:
    If netTaxableIncome <= tdsConfig.rebate_limit:
      tax -= min(tax, tdsConfig.rebate_max)

  Surcharge (from tdsConfig.surcharge_json):
    Graduated: 10%/15%/25%/37% based on income brackets
    Applied to taxAfterRebate

  Health & Education Cess: 4% of (taxAfterRebate + surcharge)

  Monthly TDS:
    monthlyTDS = (annualTaxLiability - ytdMetrics.ytd_tds) / monthsRemaining

  Returns: { tds, annual_tax_liability, tds_regime, computation_log_fragment }

SECTION 9: STATE MANAGEMENT
================================================================================

3 Zustand stores (no persistence middleware except localStorage for company).

--- auth.store.js ---
  State:
    user             : null | { id, name, email, role, company_access, force_password_change }
    isAuthenticated  : false
    loading          : false
    error            : null

  Actions:
    login(email, password):
      - Sets loading=true
      - Calls window.api.auth.login(email, password)
      - On success: sets user + isAuthenticated=true + loading=false
      - On fail: sets error message
    logout():
      - Sets user=null, isAuthenticated=false
    updatePassword(currentPassword, newPassword):
      - Calls window.api.auth.updatePassword(user.id, current, new)
      - On success: updates user.force_password_change=0

--- company.store.js ---
  State:
    companies      : []
    activeCompany  : null  (persisted: localStorage 'paysmart_active_company_id')
    loading        : false
    error          : null

  Actions:
    loadCompanies():
      - Calls window.api.company.getAll()
      - On load: checks localStorage for saved activeCompanyId, auto-restores if found in list
    setActiveCompany(company):
      - Sets activeCompany
      - Persists company.id to localStorage 'paysmart_active_company_id'
    createCompany(data):
      - Calls window.api.company.create(data)
      - Pushes to companies array
      - Auto-sets as activeCompany
    updateCompany(id, data):
      - Calls window.api.company.update(id, data)
      - Replaces in companies array

--- payroll.store.js ---
  State:
    month          : previous month (auto-calculated)
    year           : appropriate year for previous month
    activeRun      : null | payroll_runs row
    runDetails     : []    payroll_details rows
    preRunIssues   : { errors: [], warnings: [] }
    loading        : false
    error          : null

  Actions:
    setPeriod(month, year): updates month/year state
    loadPreRunFlags(companyId):
      - Calls window.api.payroll.bulkFlagCheck(companyId, month, year)
      - Sets preRunIssues
    loadRun(companyId):
      - Calls window.api.payroll.getRun(companyId, month, year)
      - Calls window.api.payroll.getRunDetails(run.id) if run found
    draftRun(companyId, operatorName):
      - Calls window.api.payroll.draftRun(companyId, operatorName) [dry run, no save]
      - Sets activeRun to preview data
    executeRun(companyId, operatorName):
      - Calls window.api.payroll.executeRun(companyId, operatorName) [saves to DB]
      - Sets activeRun + runDetails
    updateRunStatus(runId, status, user):
      - Calls window.api.payroll.updateStatus(runId, status, user)
      - Updates activeRun.status
    addOverride(overrideData):
      - Calls window.api.payroll.addOverride(overrideData)
      - NOTE: Does NOT re-run payroll after adding override — user must re-execute

SECTION 10: UTILITIES

--- constants.js ---
  INDIAN_STATES: 16 states with { value: 'MH', label: 'Maharashtra' } format
    (MH, KA, WB, AP, TS, GJ, TN, KL, MP, DL, UP, RJ, HR, PB, CG, OD)
  EMPLOYMENT_TYPES: permanent, contract, intern, probation, part_time
  MONTH_NAMES: ['January', ..., 'December']
  CURRENT_FIN_YEAR(): returns 'FY YYYY-YY' based on current month
    If month >= 4 (April): FY starts current year
    Else: FY started previous year

--- formatters.js ---
  formatCurrency(value):
    Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR' })
    Returns '₹X,XX,XXX.XX' format

  formatMonth(month, year):
    Returns 'April 2025' style string using MONTH_NAMES

  formatDate(dateStr):
    Returns 'DD Mon YYYY' format (e.g. '15 May 2025')

  calcWorkingDays(month, year, workingDaysPerWeek):
    - Iterates all days in month
    - Excludes Sundays always
    - Excludes Saturdays if workingDaysPerWeek=5
    - Returns count of working days

--- validators.js ---
  validatePAN(pan):      /^[A-Z]{5}[0-9]{4}[A-Z]$/ regex
  validateTAN(tan):      /^[A-Z]{4}[0-9]{5}[A-Z]$/ regex
  validateIFSC(ifsc):    /^[A-Z]{4}0[A-Z0-9]{6}$/ regex
  validateUAN(uan):      12-digit number
  validateAadhaar(a):    4-digit (last 4 only stored)
  validatePhone(ph):     strips +91/91 prefix, validates 10-digit mobile
  validateEmail(email):  standard email regex
  validateESICode(c):    17-digit number
  validatePFRegNumber(n): min 10 chars
  validatePincode(p):    6-digit number
  validateGSTIN(g):      15-char GSTIN format (optional)
  validateCIN(c):        21-char CIN format (optional)
  validateBankAccount(a): 9-18 digits
  getCurrentFinancialYear(): returns same as CURRENT_FIN_YEAR() but as object {startYear, endYear}

--- remote-api.js ---
  buildRemoteApi(serverUrl, apiKey):
    Returns window.api-compatible object where all calls use fetch()
    Headers: 'x-api-key': apiKey, 'Content-Type': 'application/json'

    All namespaces proxied: auth, company, employee, salary, attendance, payroll

    report namespace: returns { success: false, error: 'Not available in client mode' }
      (files must be generated on host machine)

    backup namespace: returns { success: false } stubs
      (backup must run on host machine)

    server namespace: falls back to local window.api?.server
      (network config is always local)

    sync namespace: falls back to local window.api?.sync

  Used by main.jsx bootstrap() to swap window.api in client mode

  Severity: Medium (incorrect post-override totals until re-execute)
  File: src/store/payroll.store.js

  Severity: Low (edge case only)
  File: src/pages/employees/EmployeeForm.jsx Tab 4
